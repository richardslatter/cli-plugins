Permissions

The official CLI requests repo, read:org, and gist. This is a broad GitHub credential. This service only exposes reviewed read operations.

Disconnect deletes the service’s saved credential. It does not revoke GitHub’s authorisation; revoking the GitHub CLI grant in GitHub settings can affect other CLI use. Encrypted provider backups may retain old records until their retention period ends.
